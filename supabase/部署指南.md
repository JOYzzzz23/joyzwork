# JOYZWORK v13 推送通知部署指南

## 概述
v13 新增了三大功能：热点收藏到素材库、AI工具可增删+本地APP协议+常用网址、Web Push系统级推送。

推送通知需要你在 Supabase 中执行以下配置，才能实现"关闭浏览器/手机锁屏也能收到提醒"。

## 步骤一：创建推送订阅表 + 定时任务

1. 打开你的 Supabase Dashboard
2. 进入 SQL Editor
3. 打开项目中的 `supabase/setup-push-notifications.sql` 文件
4. **替换其中的两个占位符**：
   - `YOUR_PROJECT_REF` → 你的 Supabase 项目 URL 中的 ref（例如 `https://abcdefgh.supabase.co` 中的 `abcdefgh`）
   - `YOUR_ANON_KEY` → 你的 Supabase Anon Key
5. 执行 SQL

## 步骤二：部署 Edge Function

1. 在 Supabase Dashboard 中进入 Edge Functions
2. 点击 "New Function"
3. 函数名设为 `check-reminders`
4. 打开项目中的 `supabase/functions/check-reminders/index.ts` 文件
5. 将完整内容粘贴进去
6. 点击 Deploy

## 步骤三：在 JOYZWORK 中开启推送

1. 打开 JOYZWORK 网页
2. 点击右上角通知铃铛图标
3. 点击底部的"通知 & 推送设置"
4. 点击"🔔 开启系统通知" → 浏览器会弹窗询问是否允许通知 → 点击允许
5. 点击"📡 订阅/刷新推送" → 系统会自动订阅推送服务并注册到 Supabase
6. 看到"推送已注册到云端"提示即成功

## 步骤四：手机端安装 PWA（锁屏通知需要）

### Android：
1. 用 Chrome 打开 JOYZWORK 网页
2. 点击浏览器菜单 → "添加到主屏幕"
3. 打开主屏幕上的 JOYZWORK 图标
4. 按步骤三开启通知

### iOS（需 16.4 以上）：
1. 用 Safari 打开 JOYZWORK 网页
2. 点击分享按钮 → "添加到主屏幕"
3. 打开主屏幕上的 JOYZWORK 图标
4. 按步骤三开启通知

## 验证

配置完成后，创建一个测试任务：
1. 添加一个任务，截止时间设为当前时间后 5 分钟
2. 提醒时间勾选"提前5分钟"
3. 等待 1-2 分钟，应该能在系统通知栏收到弹窗
4. 关闭浏览器标签页，5分钟后应仍能收到逾期提醒（需浏览器后台运行）

## 常见问题

**Q: 为什么关了浏览器还是收不到通知？**
A: 电脑端需要 Chrome/Edge 在后台运行（默认开启）。如果完全退出了浏览器进程，则无法接收推送。

**Q: iOS 上不支持怎么办？**
A: iOS 16.4 以下版本不支持 Web Push。请升级 iOS 或使用 Android 设备。

**Q: 定时任务执行频率？**
A: 每分钟检查一次。Supabase 免费版的 pg_cron 支持此频率。

**Q: 会消耗很多 Supabase 额度吗？**
A: 每分钟调用一次 Edge Function，每月约 43,200 次。Supabase 免费版每月 500,000 次函数调用，足够使用。
